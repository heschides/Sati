Before installing the annual-compliance update on this computer
===============================================================

The update changes how annual compliance work is identified. The first time you
start it, Sati backs up your database and converts the existing annual forms.

Install SatiLocalSetup-1.3.13.exe. It contains the same update as 1.3.11 and 1.3.12; those
misread this database at startup and refused to convert it. 1.3.13 fixes that.

The conversion is deliberately cautious. If it meets a form it cannot place in a
specific service year, it stops and changes nothing rather than guessing at a date
that decides whether work is billable. Your records stay exactly as they are, but
Sati will not open until the rows are sorted out.

This folder tells you, in advance, whether that will happen here.

WHAT TO DO
----------
1. Copy the files in this folder to your Desktop, or anywhere on your own computer.
   Running them straight from the shared folder can be blocked.

2. Double-click "Step 1 - CHECK ONLY". It changes nothing. It saves a small text file
   to your Desktop called Sati-1311-readiness.txt.

3. Read the last line of that file:

     "RESULT: ready"      - install 1.3.13 whenever you like.
     "RESULT: NOT ready"  - send the file to Josh and wait. Do not install yet.
     anything else        - send the file to Josh.

4. The file contains counts and form types only. It contains no consumer names,
   notes, or other personal information.

IF ANYTHING LOOKS WRONG
-----------------------
Close the window and send Josh whatever it printed. Nothing in Step 1 modifies the
database, so there is nothing to undo.

IF STEP 1 SAYS "NOT ready"
--------------------------
Send the file to Josh first. If he says to go ahead, double-click
"Step 2 - APPLY FIX" and type YES.

Step 2 repairs compliance scheduling only:

  - annual due dates that no longer match the schedule Sati can calculate;
  - old blanket billing overrides that the new version cannot interpret;
  - missing quarterly-review rows;
  - two stored rows that are really the same annual obligation, where it keeps the
    row carrying the recorded work and removes its empty twin.

It never deletes a row that has a recorded completion attached to it. If both rows
of such a pair have one, it leaves both alone and says so at the end. That is not a
failure; it means Josh has to look at those two by hand.

It does not change your client list, your notes, or your scratchpad. It checks the
contents of all three before and after, and undoes the entire repair if any of them
differ. It saves Sati-1311-repair.txt to your Desktop; keep that file.

Afterwards, run Step 1 again. When it says "ready", install SatiLocalSetup-1.3.13.exe
from the Sati Desktop folder, then start Sati. It backs up your database and finishes
the update itself. Starting your current version after the repair is harmless, but it
will not finish the update.
